# 快捷提醒时间编辑器设计

## 目标

将高级同步与隐私页中的“快捷提醒时间”从纵向大输入框改为紧凑、自然的胶囊编辑器，使三个默认快捷时间可以在一行内完成浏览和编辑，并保持 Tab Garden 现有的绿色视觉语言。

## 范围

- 只调整快捷提醒时间区域的 DOM 结构、交互细节和样式。
- 保留现有 `Settings.deferredShortcutMinutes` 数据结构、保存消息和数值校验。
- 不调整看板延后菜单、Supabase 同步范围或其他设置卡片。

## 视觉设计

- 卡片标题为“快捷提醒时间”，说明文案为“在‘稍后处理’菜单中显示这些常用时间”。
- 标题右侧显示 `{当前数量} / 5` 的轻量计数胶囊。
- 每个快捷时间使用圆角胶囊，内部依次包含数字输入框、“分钟”单位和删除按钮。
- 删除按钮使用 `×`，默认低对比度；悬浮或键盘聚焦时显示浅红背景和红色文字。
- 数字输入框聚焦时，整个胶囊显示绿色边框与柔和聚焦光环。
- “＋ 添加时间”使用虚线边框的轻量按钮，与时间胶囊排列在同一个可换行容器中。
- 辅助文案提示允许范围为 1–10080 分钟，保存时自动去重。

## 交互规则

- 初始渲染使用已保存的快捷时间，默认值仍为 1、3、5 分钟。
- 点击“添加时间”追加一个默认值为 10 分钟的胶囊，并将焦点移到新输入框。
- 最多允许 5 个快捷时间；达到上限时隐藏添加按钮并将计数显示为 `5 / 5`。
- 删除任一胶囊后立即更新计数；低于上限时重新显示添加按钮。
- 数字输入范围保持为 1–10080，最终保存继续由现有设置校验负责拒绝非法数据并去重。
- 键盘 Tab 顺序依次经过数字输入框、删除按钮和添加按钮，所有交互控件保留明确的可访问名称。

## 实现边界

- `src/options.html`：为该卡片增加专用结构类、计数和辅助说明节点。
- `src/options.ts`：集中创建快捷时间胶囊，复用同一创建函数处理初始渲染和新增操作；统一更新计数和上限状态。
- `src/options.css`：增加只作用于快捷时间编辑器的胶囊、删除、聚焦、计数和响应式样式。
- 不引入框架、图标库或新的运行时依赖。

## 错误处理

- 输入非法数值时沿用表单保存错误状态，不静默改写用户输入。
- 重复值沿用 `normalizeDeferredShortcutMinutes` 的保存时去重行为。
- 当已有 5 个项目时不创建第 6 个项目。

## 验证

- 自动测试检查构建后的卡片专用结构、胶囊类名、计数节点、删除按钮可访问名称和上限处理逻辑。
- 运行 `npm test`、`npm run typecheck` 和 `git diff --check`。
- 浏览器验收检查桌面与窄窗口下的换行、输入聚焦、删除悬浮、键盘顺序以及 5 个项目时的上限状态。
